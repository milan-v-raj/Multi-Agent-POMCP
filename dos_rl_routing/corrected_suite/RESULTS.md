# Earlier CMOMDP network results

> **Fidelity audit:** These older saved network runs have an expected-ARQ-attempt formula error. Energy, delay and potentially PDR and policy comparisons require corrected reruns. See `../PAPER_FIDELITY.md`.

These tables use only CSVs in this output directory. Historical results from other directories must not be mixed with them. A missing section means that stage was not complete when this report was generated. Check `status.txt` and regenerate after the suite ends.

The main agent uses a relay-only key, value-based DOS selection, and rescaled paper rewards. The separate full-snapshot experiment is a route-episode comparison, not a closed-loop policy. Compact states are not proven Markov. The simulator is not ns-3 and does not implement SDN-Q.

E0 and E0b use 30 held-out route episodes per seed; E6 uses 30 deployment runs with a separate agent trained on each deployment, not 30 unseen-to-the-agent topologies. E7 is a separate zero-shot comparison. Counts `n` below are CSV rows, generally seeds or deployments, not episodes. Statistics tables and E4 are already aggregated. Confidence interval columns averaged across seeds are not pooled confidence intervals.

`energy_efficiency` is PDR fraction per watt, not the paper’s PDR divided by average relay energy. Delay is a flow-model estimate. Comparisons of shaped and unshaped episode returns have different reward definitions; use success and network metrics as well.

Training figures, when generated: [E0](figures/e0_learning_curves.png), [E0b](figures/e0b_coldstart.png); E0 CSV values are 20-episode moving averages.
